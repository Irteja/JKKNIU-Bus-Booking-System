# 🚌 JKKNIU Bus Booking System

A web-based seat booking system for Jatiya Kabi Kazi Nazrul Islam University (JKKNIU) students. This system streamlines the reservation of seats in university buses, providing a smooth, secure, and user-friendly booking experience.

## 🔑 Key Features

- 🔍 View available buses and schedules
- 🪑 Real-time seat booking with visual seat layout
- 👤 User authentication and authorization with JWT
- 🎫 Booking history and status tracking
- ⚙️ Admin panel to manage users, buses, and trips
- 🔐 Role-based access control (Admin & Student)
- 📡 RESTful API integration

## 🛠️ Technologies Used

- **Backend:** ASP.NET Core with Razor Pages
- **Frontend:** HTML, CSS, JavaScript (vanilla)
- **Authentication:** JSON Web Token (JWT)
- **Architecture:** RESTful API
- **Database:** Microsoft SQL Server (MSSQL)


## Prerequisites

- .NET SDK (version 8.0.404)
- Visual Studio / VS Code
- SQL Server
